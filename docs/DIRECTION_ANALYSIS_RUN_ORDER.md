# Direction-analysis snapshot

The snapshot now resides in `analysis/direction_analysis/`. Its software references use the renamed distributed scripts, but its frozen-data/output paths still depend on the historical Windows project. `08_101_run_feasibility_workflow.ps1` performs source/input feasibility checks; `08_102_run_direction_workflow.ps1` performs the fixed family-balance, healthy-reference and sensitivity calculations. The timestamped specification is retrospective and was written after the original distance findings. Use `tools/01_reproduce_selected_statistics.R` for the flat-input statistical subset. Raw data, full frozen objects and patient inputs are not included in this public snapshot. Original software is MIT-licensed; data redistribution review remains separate.
