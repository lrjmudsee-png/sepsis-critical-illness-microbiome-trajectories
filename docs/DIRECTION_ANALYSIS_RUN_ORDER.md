# Direction-analysis snapshot

The 99_DIRECTION_UPGRADE snapshot is retained as execution provenance. Its original runners are Windows-path bound. RUN_A performs source/input feasibility checks; RUN_B performs the fixed family-balance, healthy-reference and sensitivity calculations. The timestamped specification is retrospective and was written after the original distance findings. Use the portable selected-statistics runner for the flat-input statistical subset. Raw data, full frozen objects and patient inputs are not included in this public snapshot. Publication of processed input files and final licensing/citation creators remains author pending.
