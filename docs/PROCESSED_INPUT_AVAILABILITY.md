# Code and data availability as of 18 September 2026

Raw public data: PRJNA691455, PRJNA516701, PRJNA851469, PRJNA578267, PRJNA430161, PRJNA1166732, PRJNA978257, PRJNA1010969, PRJNA1125274 (NCBI); PRJEB82425 (ENA); CRA002354 (NGDC-GSA).

Analysis code and historical run order: https://github.com/lrjmudsee-png/sepsis-critical-illness-microbiome-trajectories. The repository includes the 99_DIRECTION_UPGRADE scripts and portable selected-statistics runners. Original code and associated software documentation are MIT-licensed, copyright (c) 2026 Lu Rongji; [this does not relicense research data](LICENSING.md). No Zenodo publication or new release is made by the licensing update.

Reproduction scopes are separate: the historical 11-step terminal run tested frozen objects to manuscript outputs; Step98 reproduced external statistics from frozen objects; the direction stage matched 28 deterministic outputs; the portable reviewer bundle reruns selected statistics from flat frozen inputs, without recomputing ASV-level distances. The raw-read-to-manuscript historical route has not been freshly verified on an independent machine and remains partly Windows-path dependent.

The minimized selected-statistics input bundle contains public-alias-derived identifiers and derived measurements without names, contact details, exact collection dates or linked clinical covariates. It is supplied with the manuscript as Supplementary Data 5 and is intended to be available with the published article. The public code repository alone is not sufficient to rerun every analysis because full frozen ASV/OTU objects are not distributed. The input manifest/data dictionary and availability limitations are explicit. Clinical 132-person roster, individual host measurements and full attrition/confounding covariates were unavailable.

Software citation metadata are active in `CITATION.cff` and aligned with the manuscript CRediT statement, with Rongji Lu listed as the software creator. Zenodo remains deferred until the submission snapshot and processed-data redistribution plan are finalized. A DOI must not be invented before an archival record is actually created. A final article DOI is not required to archive a software version while the article is unpublished.
